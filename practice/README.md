# Практические файлы

[Главная](../README.md) · [Условие проекта](../projects/README.md)

| Файл | Для чего |
|---|---|
| [starter.sql](starter.sql) | Минимальная учебная база для J08–J10, данные с отсутствующими связями и повторными попытками уведомления |
| [openapi-example.yaml](openapi-example.yaml) | Один метод OpenAPI 3.1.1 как пример структуры, ссылок и nullable-поля |
| [sequence-example.puml](sequence-example.puml) | Редактируемая UML sequence чтения собственной записи |

SQL запускай в отдельной учебной БД. Повторный запуск без очистки завершится ошибкой создания таблиц. Даты в данных фиксированы: используй согласованное `as_of`, а не текущее время. Упражнения требуют расширить схему и набор данных.

Эти файлы не являются готовым решением итогового проекта. В OpenAPI указан примерный URL, действующего backend по нему нет.

Исходная проверка: YAML разобран, локальные `$ref` и пример ответа сверены; SQL-фикстура выполнена на SQLite для проверки связей и контрольных количеств. На PostgreSQL в этой среде не запускалась. PlantUML подготовлен как текстовый пример; отдельный рендер не выполнялся.
