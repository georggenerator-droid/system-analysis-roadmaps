# J09 Освой SQL на одной таблице

[← Маршрут](../README.md) · [Назад: J08](j08-data-modeling.md) · [Дальше: J10 →](j10-sql-joins.md)

**Результат:** ты самостоятельно получаешь нужную выборку и проверяешь её смысл. Ориентир — 24 часа.

Нужны SELECT, FROM, WHERE, ORDER BY, LIMIT, DISTINCT, AND/OR/NOT, IN, BETWEEN, LIKE, IS NULL, CASE, агрегатные функции, GROUP BY и HAVING. Дополнительно разбери INSERT, UPDATE, DELETE и простую транзакцию BEGIN/COMMIT/ROLLBACK. Практикуй изменение только на своей учебной базе.

Сразу учись читать вопрос к данным: что является одной строкой результата, какие объекты включаются, за какой период и что делать с отсутствующими значениями. Если эти условия не выяснены, синтаксически верный запрос всё равно может отвечать неверно.

**Обязательно:**

- [S22 Язык SQL в документации PostgreSQL](https://postgrespro.ru/docs/postgresql/17/tutorial-sql) · RU. Пройди создание, наполнение, выборку, агрегаты, изменение и удаление строк. Повторяй команды в своей базе.
- [S28 SQLBolt](https://sqlbolt.com/) · EN. Пройди уроки 1–4, повторение SELECT и уроки об агрегатах. Синтаксические отличия сверяй с PostgreSQL.

**Альтернатива и видео:**

- [S29 Интерактивный тренажер по SQL](https://stepik.org/course/63054/promo) · RU. Русский тренажёр: блоки с одной таблицей и агрегатами. В учебных заданиях возможен другой SQL-диалект. Поиском курс подтверждён, прямое открытие в проверке не сработало.
- [V03 CS50 SQL Week 0 Querying](https://cs50.harvard.edu/sql/weeks/0/) · EN. Querying: SELECT, фильтрация, сортировка и агрегаты. Можно читать Notes вместо просмотра всей лекции.

**Сделай:** заполни таблицу занятий минимум 20 строками: разные даты, вместимость, отменённые занятия, нулевое количество записей. Напиши 15 запросов: будущие занятия; занятия за период; поиск по части названия; пять ближайших; число занятий по дням; средняя вместимость; дни с более чем тремя занятиями; строки с отсутствующим описанием. Перед каждым запросом напиши ожидаемые строки или число строк, затем сравни результат.

Отдельно покажи разницу COUNT(*) и COUNT(description), WHERE и HAVING, AND/OR со скобками. Выполни UPDATE внутри транзакции и откати. Объясни, почему отсутствие WHERE при изменении опасно.

**Самопроверка:** почему сравнение `= NULL` не подходит? Как определить порядок строк? Включает ли BETWEEN границы? Почему фильтр по последнему дню может потерять часть записей с временем? Чем запрос количества отличается от списка объектов?

**Готово, когда:** решаешь 8 из 10 новых небольших задач без готовых ответов, проверяешь результат на тестовых данных и объясняешь каждую часть запроса. При ошибке сначала проверь данные и условия, затем синтаксис.
