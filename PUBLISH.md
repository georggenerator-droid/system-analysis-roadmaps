# Публикация и обновление

[Главная](README.md) · [Материалы для ментора](mentors/README.md)

## Загрузка

1. Распакуй архив `system-analysis-roadmaps-git.zip`.
2. Открой папку `system-analysis-roadmaps`.
3. Загрузи **её содержимое в корень репозитория**: README.md, CONTENTS.md и папки assets, roadmaps, resources, projects, practice, templates, downloads, mentors, tools.
4. Открой главную страницу репозитория: README покажет обзорную карту и навигацию. Относительные ссылки сохранятся при любом имени репозитория.

Если используешь Git локально, эту папку можно сделать корнем нового репозитория. Файлы уже готовы для первого коммита. Публикация через GitHub Pages и установка зависимостей для чтения не нужны.

## Где редактировать

| Изменение | Файл или папка |
|---|---|
| Главная и описание | README.md |
| Теория, задания и ссылки блока | roadmaps/zero-to-junior/modules или roadmaps/junior-to-middle/modules |
| Дополнительные темы | roadmaps/middle-plus |
| Условия проекта | projects/README.md |
| Источники | resources/README.md и resources/sources.json |
| Шаблоны | templates |
| Подписи и состав карт | assets/source/roadmaps.json |

Редактируемые страницы в roadmaps — основная версия. PDF в downloads — снимок исходной версии 1.0; после изменений текста они не обновляются автоматически.

## Обновление изображений

Карты уже готовы в PNG и SVG. Для обычной загрузки ничего запускать не нужно.

Если меняешь подписи, исправь `assets/source/roadmaps.json`, затем запусти:

```bash
python3 -m pip install Pillow
python3 tools/render_maps.py
```

Скрипт использует DejaVu Sans или Arial. При необходимости передай путь к шрифту через `ROADMAP_FONT_REGULAR` и `ROADMAP_FONT_BOLD`. Для корректной кириллицы шрифт должен её поддерживать.

Проверка локальных ссылок и наличия всех блоков:

```bash
python3 tools/check_links.py
```

## Как добавлять материалы

Пиши, что именно читать или смотреть и зачем. Указывай язык, обязательность и дату проверки. При добавлении новой обязательной темы одновременно обнови практику и критерии сдачи. У видео различай найденную страницу записи и проверенное воспроизведение.
